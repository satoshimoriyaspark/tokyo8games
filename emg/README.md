## モード
「じっくり防災」だけ採用。「サクッと防災」はモード選択・ルール・UI・チュートリアルから除外。
1〜4体のモンスターに連続挑戦でき、4体封災で完全封災。最初はソロ＋CPU仲間の開発テストを行うが、紙版の人数別ルールを勝手に変更しない。

## カード構成
ディザスターモンスター4 / ガーディアン10 / マモリギア24 / アクション8 / ハプニング8 = 54枚。
5属性: しる・そなえる・みをまもる・にげる・たすけあう。
完成カードの正本と透過MAIN素材は別々に読み、カードから飛び出す演出では透過MAINを使用。承認済みFIX台帳／SHA-256との一致を必須とし、仮キャラは正式リリースに含めない。カード裏面はv05を使用。

## 正式ルール（10/5更新）
- 事前にプレイヤーごとにガーディアン候補2体から1体を選ぶ。未選択は山札へ戻す。交換は新しいガーディアンを引いたときのみ。使用済みガーディアンも交換でき、新しいガーディアンの能力は未使用。
- 初期手札3枚はギア24＋アクション8からのみ配る。残りのギア／アクションに未選択ガーディアンとハプニング8を混ぜて1つの山札にする。
- 各手番は無料ドロー → 即時効果・ガーディアン交換 → 相談 → 1アクション（ギアを置く／アクションを使う／何もしない）→ 5枚手札上限の確認。
- ハプニングは引いたとき即解決して捨て札へ。山札が空なら捨て札をシャッフルして再利用。
- 5属性をすべて封災スロットへ置くと1体封災。使用した5枚は捨て札へ。次戦は手札3枚まで選択して持ち越し、山札／捨て札／ガーディアン状態を維持。
- 危険度は人数によらず1開始。全員1回ずつのラウンド末に+1、危険度7で敗北。次戦は1へ戻る。
- 固有能力はガーディアンごとに1回、使用時に横向き。廃止済みの「ギアリンク」を実装しない。
- モンスター固有効果はルール資料内で「現行候補」であり、FIXカード面との照合が終わるまで実装をロックする。

## アニメーション
- UIはスマホ縦画面優先。手札をタップで拡大、カードをプレイする時は元カードフレームを残してキャラクター透過レイヤーを前方へ2.5D移動。
- ディザスターモンスター登場、ガーディアン能力、マモリギア配置、ハプニング、危険度変化、封災成功、完全封災に個別エフェクトを用意。
- 主要なキャラクターはカードから飛び出すが、別の汎用モンスター／人物画像を生成して置換しない。
- 軽量モードとOSのprefers-reduced-motionを尊重。スキップ可能にする。
- 子ども向け本文は必要な漢字にふりがなを付ける。正式5属性アイコンをそのまま使用。

6. プレビューでの動作確認後、公開は別途行う。
