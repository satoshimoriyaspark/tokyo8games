# ゲーム公開方式

## 共通ルール

正式URLは `https://tokyo8games.com/xxx` とし、原則3文字の小文字英字を使用します。ゲーム本体と必要素材をTOKYO 8 GAMESで配信し、プレイ中もこのURLを維持します。外部ゲームへの単純転送・外部ページの代理配信・iframe埋め込みは正式公開に使いません。

サイト内の案内、チラシ、QRコード、SNS、β版の案内にも正式URLを使用します。開発用URLは一般向けに案内しません。将来の実装や配信環境の変更では、正式URLを維持して内部の配置先を変更します。

| パス | ゲーム | 現在の配信方式 |
| --- | --- | --- |
| `/kks` | かつしか郷土かるたスタジアム｜トレーニング編 | `games/kks/index.html` を内部rewriteで配信 |
| `/kwb` | 亀有わっしょいバトル | 既存の転送設定を維持。今回の移植対象外 |
| `/w` | 亀有わっしょいバトルの旧パス | 既存互換用。新規案内には使用しない |

## KKSの構成と維持事項

- 元の公開β版: Sites version 10 / source commit `fdbd1fd09ec477a9041039fd1b8d6a96e2d9dcf3`。
- `games/kks/`: HTML、CSS、JavaScript、カードデータ、絵札44枚、ロゴ。素材のバイト列とゲームルールは維持。
- `/kks` からローカルHTMLへ内部rewrite。HTMLのbaseによりCSS・JS・画像・カードJSONを同じドメインの `/games/kks/` から読み込む。
- 音声ファイルは元ゲームに存在しない。日本語音声はWeb Speech APIによる端末の読み上げをそのまま使用。
- `/api/kks/{profile,leaderboard,runs,finish}`: Vercel Function。既存のランキングAPI・D1データベースへサーバー側で接続する。画面本体の配信・転送には使用しない。
- 既存のランキングデータを削除・初期化しない。旧バックエンドはこの依存が解消するまで稼働を維持する。将来は同じAPI契約を保ったまま保存先を変更できる。
- ドメインが変わるため、旧ドメインのHttpOnly識別Cookieは引き継げない。既存記録はランキングに残るが、新URLでは新しいブラウザー識別になる。名前編集と自己ベストは新しい識別で記録される。
- Cookieは `Secure; HttpOnly; SameSite=Lax; Path=/api/kks`。他機能のCookieをバックエンドに渡さず、POSTのOriginを検証し、転送先とAPIを固定する。ランキングAPIはキャッシュしない。
- トップページのKKSリンクは `/kks`。他ゲームのリンク・転送設定、問い合わせAPI、DNS、環境変数は今回変更しない。

## 公開前後の確認

1. `/kks` のHTTP応答が200であり、外部Locationヘッダーを返さない。
2. PC、iPhone、iPadの画面幅で表示、札の選択、スクロール、12/22/44枚、タイトル戻りを確認。
3. 全画像とJS/CSS/JSONを同じドメインから取得できる。欠けた素材を置き換えない。
4. 読み上げ、聞き直し、休憩、ヒント、お手つき、取得演出、結果、タイムアタックとランキングの通信を確認。
5. 本番ランキングに自動テストの得点を混入させない。完走・保存テストは隔離データで実施。
6. トップページからの遷移、他ゲームの既存経路、問い合わせページの維持を確認。
7. GitHubコミットとVercelのProduction反映を照合。実機未確認の項目は明記する。
