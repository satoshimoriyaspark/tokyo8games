# サッカークイズ・v2スプライト組み込み（PLAYTEST 0.6）

対象: feature/soccer-quiz-beta / games/sqz/。本番へのマージ・反映は行わない。

## 実装

- 正解: 既存ピンポーン音 → キック → ボール飛行 → キーパーが逆側へダイブ → ネットが揺れる → GOAL! → 答え・解説と「次の問題へ」。既存の学習用手動進行を維持。
- 不正解・時間切れ: 既存ブザー → キック → 同じコースにダイブ → 手袋へボールを固定し着地 → SAVE! → 正解・解説。
- 3、6、9問連続正解で SUPER SHOT! と炎色の軌跡。
- 各方向8フレーム、110ms/フレーム。80×80のセルを一定サイズで描画し、全体の移動を補間。セーブ以降はボールが手袋のアンカーに追従。
- 約1.75秒の演出、スキップ、端末の視差効果削減設定に対応。離脱・非表示・再開時は採点を再実行しない。
- 回答後は問題と選択肢を折りたたみ、解説を上部へ配置。短い画面では演出領域を縮める。出典および問題・選択肢は展開して確認可能。
- 200問の問題データ、保存キー、確定ロゴ、音のON/OFFと既存合成音、他ゲームとルーティングを維持。

指定の `keeper_animation_v2.zip` 内の `keeper_atlas.png` / `keeper_atlas.json` / `README.txt` をそのまま使用。PNGは640×160のRGBA、左右各8セル。原本PNGとのバイト一致を確認。画像の再生成・差し替えなし。
