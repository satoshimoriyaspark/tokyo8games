# サッカークイズ スプライト v3 / PLAYTEST 0.7

対象: feature/soccer-quiz-beta、games/sqz/。本番反映なし。

## デザイン更新

指定のデザイン参考PNGを主資料、提供済みkeeper v2 atlasを動作資料として、内蔵image_genで新しい透過PNGを制作した。新PNGは1254×1254 RGBA、約825KiB。既存v2は履歴・資料として残し、ゲームの表示はv3を使用する。

- 赤いキーパー: 茶色の髪、大きい頭、太い黒輪郭、角張ったドット絵、白いグローブ。
- 青いストライカー: 同じ画風の青いユニフォーム、黒いパンツ。従来の黄色いCSS仮キャラクターを置き換え。
- キーパー8ポーズ: 構え、沈み込み、踏み切り、空中、キャッチ姿勢、横向き保持、着地、伏せた保持。左方向は同じ8ポーズを体の基準点を中心に反転し、頭身と手足の大きさを維持する。
- ストライカー8ポーズ: 待機、助走、振りかぶり、キック、振り抜き、復帰、喜び、悔しがる。

PNGの透過・描画内容は生成結果をそのまま使用。各キャラクターを囲む矩形、体の基準点、グローブ接触点をframes.jsonに記録した。ランタイムで矩形を切り出し、同じ0.30倍の尺度で表示する。フレームごとの幅・高さを同一サイズへ引き伸ばさない。キーパーの横移動・ジャンプ・着地は体の基準点から計算する。

## 演出

正解はキーパーと反対側にゴール、不正解はキャッチしたボールがグローブに追従。3問連続正解ごとのSUPER SHOT、ネットの揺れ、スキップ、解説、問題折りたたみは維持。約1.75秒で演出終了。200問のデータ、確定ロゴ、音程、採点、保存キー、他ゲームは維持。

## 生成方法とプロンプト

内蔵image_genの編集モード、transparent_background=true。
参照1: Google Driveの「目指せクイズ王_サッカー編_キャラクターデザイン参考_v1.png」。参照2: 提供されたkeeper_animation_v2.zip内のkeeper_atlas.png。

生成指示: 参照1の太い黒輪郭・角張った2頭身・茶色の髪・顔とユニフォームを基準に、参照2の細身の試作を修正する。透明背景の4列×4行アトラス。上2行に赤いキーパーの右ダイブ8段階（構え、沈み込み、踏み切り、斜め空中、水平キャッチ姿勢、水平保持、着地、横たわった保持）、下2行に青いストライカー8段階（待機、助走、振りかぶり、キック、振り抜き、復帰、喜び、悔しがる）。全フレームの頭・体・手足の寸法を揃え、肩・肘・手首を自然に接続する。キャラクター全体を切らず、周囲に余白を取る。ボール・ネット・文字・地面・背景・エフェクトは描かない。
