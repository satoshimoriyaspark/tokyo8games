# 目指せ！クイズ王 サッカー編 — PLAYTEST 0.1

作成日: 2026-10-11
開発ブランチ: feature/soccer-quiz-beta
実装: games/sqz/index.html
候補公開パス: /sqz（このブランチの内部rewriteのみ。本番へは未マージ）

## 承認仕様と現在の実装
スマートフォン縦画面を基本とする1人用4択クイズ。タイトル→導入ストーリー→難易度選択→予選・準決勝・決勝→結果。初級・中級・上級から選択。各ラウンド10問、1問20秒。突破条件は予選6問、準決勝7問、決勝8問以上。最後まで遊べて、敗退ラウンドから再挑戦可能。正解でGOAL、不正解でSAVE、3問連続正解ごとにHAT TRICK演出。回答後は解説を読み「次へ」で進む。

トレーニングはジャンル選択・時間無制限。間違えた問題の復習も可能。問題数が10問未満の復習等は存在する問題だけ出す。端末内保存、中断再開、優勝回数・最高得点・正解率・連続正解記録、保存拒否時の警告を実装。タブ非表示時は時間停止。

問題は114問。選手32、ワールドカップ28、リーグ・クラブ30、国旗24。問題の難易度は初級47・中級44・上級23。大会では選択難易度以下を母集団とし、その難易度と未出題問題を優先。突破済みラウンドの問題は同じ大会で再出題しない。履歴を使って再挑戦時の重複も減らす。

## データ・出典
全問にID、ジャンル、難易度、選択肢4つ、正解、独自の短い解説、出典URL、対象年・シーズン、確認日、公開判定を保存。歴史的な記録に対象時期を固定し、現在の所属・最新成績は出題しない。男子ワールドカップは1998〜2022の7大会。リーグはプレミアリーグの選定シーズン。国内クラブは2011〜2020年度天皇杯。

確認した公式資料:
- 日本サッカー協会: https://www.jfa.jp/samuraiblue/worldcup_history/ （各大会ページ）
- プレミアリーグ優勝記録: https://www.premierleague.com/en/premier-league-explained
- プレミアリーグ年間最優秀選手: https://www.premierleague.com/en/news/3489431
- 天皇杯歴代優勝: https://www.jleague.jp/emperorscup/2025/history.html
- 外務省国旗一覧: https://www.mofa.go.jp/mofaj/kids/kokki/list.html

2010年大会は得点首位が4人同数のため、トーマス・ミュラーの問題は国と得点を指定して曖昧さを避ける。クラブ名を問題・選択肢中に文字として記載するが、公式・公認ゲームと表示しない。

## 素材と権利確認
実在選手の写真とクラブエンブレムは未収録。エンブレムのジャンルは非表示。素材許諾台帳ASSETSは空で、approved・gameUse・evidence・checkedAtと期限を満たさない素材は出題しない。将来追加時には画像表示の実装、クレジット・改変・公開地域・期限も照合すること。広告/SNSでの使用可否はゲーム内利用と別項目として記録する。素材の利用が適法と一括判定したものではない。

国旗は端末内の標準絵文字で表示。外部の旗画像は転載していない。国旗が文字になる端末では国旗問題OFFを提供。ロゴ・選手・ピッチは今回作成したHTML/CSSによる仮デザイン。正式アート未制作。SEはWeb Audio合成、初期OFF。BGMなし。
