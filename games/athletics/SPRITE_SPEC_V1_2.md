# 8BIT ATHLETICS｜Web版・IchigoJam共通仕様書 Ver.1.2
更新: 2026-10-11 / スプライト制作移行版。現時点では仕様書確定案でありPNG素材の完成ではない。

## 1. 継承するゲーム仕様
5種目（100m、1500m、110mハードル、走り幅跳び、ジャベボール投げ）、A/Bの簡単操作、最大4人（YOUとCPU3人）、1種目1000点・総合5000点を維持。Web版はTOKYO 8 GAMES、IchigoJam版は教材。今回の変更対象はキャラクターの描画方式とアニメーション。

## 2. デザインコンセプト
かわいい2.5〜3頭身のオリジナル8bitアスリート。少し大きめの頭、表情が読める片目、小さな鼻と頬、控えめな髪の跳ね、色付きヘアバンド。細すぎず厚すぎない短い胴体、肘と膝が明確に見える腕脚。横向き走行時は右へ顔を向ける。ガッツポーズと表彰台では正面を向く。元作品ハイパーオリンピックのポーズのメリハリを参考にしてもキャラ絵を複製しない。
プレイヤー＝黄色、CPU1＝青、CPU2＝赤、CPU3＝緑。色だけでなくYOU/CPUラベルも維持する。

## 3. 制作フォーマット
- 1コマは32×48px、RGBA透過PNG、アンチエイリアス無し、拡大は整数倍を原則とする。
- フレームの足元基準線は全コマ共通でy=45。画像の各フレームは等幅で余白の追加なし。
- アニメごとに横1列のスプライトシート。例：sprint_right.png は8コマ×32=256×48px。
- WebではCanvas drawImageの9引数版でフレームを切り出す。imageSmoothingEnabled=false。
- 素材保存先 games/athletics/assets/sprites/player/ および cpu_blue、cpu_red、cpu_green。同じフレーム座標で色違いを制作。
- sprite_manifest.jsonに id / path / frameWidth / frameHeight / frames / fps / loop / anchorX / anchorY / direction を記載する。
- 画像取得失敗時には現行のコード描画をフォールバックとして残す。

## 5. 走行8コマの演出指示
1. 前膝上げ・後脚蹴り、逆腕を前へ
2. 前膝最高点、肘が強く曲がる
3. 前脚展開、後脚を回収
4. 前足着地、体幹1px沈む
5. 左右反対の膝上げ
6. 反対膝最高点、逆側の腕振り
7. 反対の前脚展開
8. 反対足着地して1へ循環
全コマで肩→肘→手と腰→膝→足を明確な折れ線シルエットにする。腕と脚は逆位相。右向きの片目・鼻は各コマで一定。上下動は最大1〜2px。

## 6. 動作タイミング
- READY中はidle_right固定、GO以降にstart_right（非ループ）→sprint_rightまたはjog_right。
- 速度に応じて基本6〜12fpsで切替。描画更新速度は競技の判定ロジックとは分離。
- ゴールは選手胸部の基準位置で判定、記録を確定後約2秒の駆け抜けを再生。ゴール後の時間は記録に含めない。
- 結果でvictory_front、総合上位3人にはpodium_front。正面ポーズは横向きランナーを流用しない。
- ハードル・幅跳び・投てきは専用ポーズを準備する。得点換算・大会進行・保存ロジックを変えない。

## 7. IchigoJamとの整合
PNGはWeb専用。IchigoJamでは文字・簡易ドット等に縮約する。同一の操作・競技ルール・キャラクター識別・結果判定を優先し、画像解像度の一致は要求しない。

## 8. 制作順序と検収
Phase A：黄色の主人公の待機（右）・ダッシュ代表姿勢（右）・表彰台姿勢（正面）の3点を32×48基準で制作、可愛さと顔の向きを確認。
Phase B：sprint_right全8コマ＋jog_right全6コマ。ループ動画で肘と膝の角度変化を確認。
Phase C：CPUの色差分、各競技専用モーション、sprite_manifest.json。
Phase D：開発ブランチのみでCanvasのコード描画をPNG表示に差替。旧描画フォールバックを維持。
Phase E：iPhone/Android/PCの実機で操作、開始静止、脚の速度連動、CPU3人、ゴール判定、結果・表彰を検証後に本番移行判断。

検収条件：かわいいオリジナルのシルエット／右向きの片目と鼻／腕と膝が各ポーズで十分に曲がる／走る速さが視覚に連動／GOまで静止／胸がゴールラインを越える瞬間にタイム確定／表彰は正面／CPUの色・順位が判別可能／5種目・大会モードが壊れない。

## 9. 実制作の最初の納品物
プレイヤーの3点比較画像（右待機・右ダッシュ・正面表彰）と絵柄確認。絵柄FIXの後に8コマシートを書き出して統合する。
