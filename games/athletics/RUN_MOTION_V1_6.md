# 走行再生 RUN 1.6

対象は `feature/8bit-athletics-web-beta` の `games/athletics/`。ART 1.5.1の承認PNGをそのまま使用し、走行の再生処理を変更する。顔・髪型・頭身・ユニフォーム・色は変更しない。

## 修正

- 旧処理は `floor(移動距離×2.8)`（1500mは×1.2）でフレームを選び、通常競技の最高速度では100mが約14.7fps、1500mが約25.5fpsとなり、足運びが読みにくかった。
- 選手ごとに固定ステップで更新するアニメーション時計を用意。実際の移動速度に応じて6〜12fpsで再生し、高速でも1コマを約83ms以上表示する。
- 動き始めのスタート3コマを各80ms、計240msで一度表示してから走行8コマへ接続。移動距離でスタートコマを飛ばさない。
- 100m系は半周期ごとに0→1→2→1px、1500mは0→1→1pxの上下動。接地コマでは元の足元基準へ戻す。胸部のXアンカーは維持。
- GO前、移動停止時は静止。ゴール通過後もアニメーション時計を継続し、減速に合わせて切り替える。再挑戦では全4選手の時計をリセット。
- ハードルの空中姿勢、ジャベボール専用姿勢、幅跳びの既存試技姿勢は優先表示を維持。得点・タイム・距離・入力・大会進行のシミュレーションは変更しない。

## 確認用

- `tests/motion.html`: 修正前（f8bf302）と修正後の実描画を同じPNG・移動速度で再生。速度変更、一時停止、スタート再生、モーション検証ボタン。
- `tests/motion-probe.js`: 低速／高速の全コマ、12fps上限、30/60fps同一時計、静止、ゴール継続、記録固定、リセットを検証。
- `tests/visual.html`: 既存の競技動作・タイム・得点・大会進行の比較検証を継続。

今回はPNGの手足のポーズ自体を新しく描き直した版ではなく、既存コマの走行再生の改善。幅跳びの専用モーションは対象外。本番mainへは反映しない。実機・Safariの確認とは区別する。

## 確認記録

2026-10-12、Vercel PreviewのクラウドChromeで100m・1500mの比較再生を確認。通常ゲームでもSTART・A/Bキー操作による走行を確認した。
モーション16項目がPASS。競技の既存206項目もPASSし、決めた入力に対するタイム・得点・大会合計は比較元と一致。素材ディレクトリはf8bf302から変更なし。実機・Safariは未確認。
