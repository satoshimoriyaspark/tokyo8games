# 8BIT ATHLETICS 1.5.1 表示修正

対象: `feature/8bit-athletics-web-beta` / `games/athletics/`。
比較元: `0638498e021abb396eb7b50a4b549a7a800b032d`。
実表示確認済み修正コミット: `759191190500a26e692263c6b8e2fe96996a28ca`。

## 原因と対応

1. PNG外周に、不透明な灰色 `RGB(184,189,200)` が残っていた。画像自体の残りであり、半透明補間や隣接コマの混入ではなかった。48×48の各セルで透明領域と4近傍でつながる、この色だけを除去した。7枚・234画素。内部の灰色と、靴・服・目などの白 `RGB(250,246,239)`、その他の色は変更していない。顔・髪型・頭身・角張った輪郭も保持。
2. ゴール前18距離以内で描画する短いテープ（24×3と3×8の矩形）が、ゴールラインに落ち物のように見えていた。この描画だけを削除。
3. ゴールラインの縞を描く `rect` 呼び出しで高さの引数が欠落していたため修正。同じ座標・幅6・高さ212の範囲に収めた。胸部の通過判定は変更していない。
4. フレームサイズ48、切り出し整数座標、描画整数座標、補間無効を明示。PNG寸法・フレーム数・胸部アンカー・足元の基準は変更なし。
5. 通過直後の既存祝福演出は保持し、走行競技の `finishDash` 状態・0〜1.1秒だけに限定。ジャベボール飛翔は第5種目の試技間だけに限定されていることを確認。使われていなかった `goalBurst` 変数を整理。
