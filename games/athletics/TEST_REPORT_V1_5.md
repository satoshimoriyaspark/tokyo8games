# ART 1.5 ローカル検証記録
2026-10-11

対象: 承認画像から切り出したPNG12枚を読み込むVer.1.5。リポジトリへ登録したPNGは制作ファイルのGit blob SHAと照合済み。
環境: Chromium headless、900×1100、390×844のタッチ端末エミュレーション。物理iPhoneではない。画像内蔵HTMLを使用し、ゲーム更新をテスト専用時計と入力で進めた。出荷HTMLにはテスト用状態変更APIを含めない。

確認済み:
- 12枚読込後にプレイヤーとCPU3人をPNGで表示。
- 待機中の画面が静止。
- A/B交互入力で100mを終了し、ゴール後の時間は記録に加算しない。
- ハードルの専用7コマが着地まで進み、走行へ戻る。
- ジャベボールのB長押し、放球、フォロースルーを切り替え、独立したボールを描画。
- 5種目大会、幅跳びと投てき各3回、表彰、総合結果まで遷移。
- 390px幅のレイアウトに横方向のはみ出しなし。
- PNG読込失敗時はSTART無効、別キャラクターを描画しない。
- テスト時計を使用しないHTMLでもカウントダウンとキーボード操作、走行を確認。
- 検証中のJavaScript pageerrorは0件。

未確認: 実機iPhone/Safari、公開URL上の描画、長時間連続操作と全ての境界条件。オンラインビルド成功のみを実機検証の代わりには扱わない。
