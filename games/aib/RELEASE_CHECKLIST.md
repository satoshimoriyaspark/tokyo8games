# 相棒ファンゲーム 個人利用・本番配置チェック

## 本番配置
- ゲーム本体は本番サーバーへ配置する
- 一般公開URLは有効化しない
- `/aib` / `/aib/cards` / `/games/aib/...` は非公開ページへルーティングする

## 公開時の表示
- 「ファンゲームです」を明示
- 公式ロゴ・写真・映像・音声は不使用
- 公式および制作関係者とは関係がない旨を表示

## 機能
- 2〜6人
- 各自6枚
- 2枚ペア提示
- 承認 / 異議あり投票
- 捜査継続: 1枚交換
- 人事異動: 全手札交換、各自1回
- 長押し人物紹介
- カード図鑑
- 1端末パス＆プレイ
