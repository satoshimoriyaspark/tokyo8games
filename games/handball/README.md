# 熱血ハンドボール7 — command β6

Preview専用。開発ブランチ `feature/handball-playable-beta3`、パス `/handball`。本番公開はユーザー確認後。

## 体験を変更した理由

β5の自動移動・作戦ボタンでは遅攻が伝わりにくかったため、β6は守備陣形が整った状態から始まる4拍のコマンド対戦に変更した。通常の攻守交代ではセンターにボールを戻し、両チームが陣形を整えてから入力を受け付ける。勝手にパス・シュートはしない。選手の移動とパスの行き先は自動。

## 3つのボタンと4拍

同じ3つの大きなボタンを、現在の状態に合わせて切り替える。別のコース決定ボタンは設けず、コースを押せばそのままシュート／GK対応を実行する。

| 状態 | ボタン1 | ボタン2 | ボタン3 |
| --- | --- | --- | --- |
| 攻撃1〜3拍 | パス | ポスト | シュート |
| 攻撃4拍／速攻 | 右 | 左 | 股下 |
| 3パス後の4拍 | ステイ | ステイ | ステイ |
| 守備1〜4拍 | カット | ブロック | ステイ |
| GK勝負 | 右 | 左 | 股下 |

PCは1・2・3またはZ・X・C。Escで一時停止。演出中の連打・キーリピートは無効。

早い拍でシュートを選んだ場合は、残りの2〜3拍目のコマンド入力を無効にして自動でスキップする。4拍目のコース選択は必ず受け付ける。シュートを選んだ拍がブロックとの照合対象。4拍目まで引っ張った連携は4拍目が照合対象になる。

| 入力1〜3 | 4拍目 | 結果 |
| --- | --- | --- |
| パス・パス・パス | どれでもステイ | 攻撃継続、次のシュートを強化 |
| パス・パス・シュート | コース選択 | センターからシュート |
| パス・シュート・スキップ | コース選択 | サイドからシュート |
| シュート・スキップ・スキップ | コース選択 | センターからロング |
| パス・ポスト・シュート | コース選択 | ポストシュート |
| パス・ポスト・ポスト | コース選択してシュート | 2回目のポストがフェイント |
| パス・ポスト・パス | コース選択してシュート | ポストから戻してシュート |

「パス→ポスト→ポスト→シュート」等の4つ目のシュートは、4拍目のコースボタンによる実行として統一した。ステイ時のみ4拍目はコースではなく継続確認。待ち時間に試合時計は進まず、1拍につきゲーム内3秒進む。180秒制で、最後の攻撃／シュートは解決してから試合終了。公式試合時間・ルールの完全再現ではない。

## 遅攻とパス

センター→片側サイド→センター→反対側サイド…の順番。端に来たら折り返す。最初の方向は攻撃ごとに交互。ポストを選ぶと受け手がゴール前に入り、もう一度ポストならフェイント。ポストからパスを出せば外側へ戻る。

3回パスのステイはボールを失わず、センターから新しい4拍を開始。連携回数と次のシュート補正を保持する。ステイは最大2回、パスは最大5回分まで補正し、無限に確率を上げられない。シュートまたは攻守交代で消費・解除する。

## 守備・速攻・GK

- 守備は4拍。カット／ブロックは合計1回、ステイは最大3回。使えないボタンは無効になる。
- パスとカット、シュートとブロックが同じ拍なら確実にフィールド守備成功。タイミングが違えば成功しない。ポストコマンドはカット対象外。
- カット成功時、乱数が1/3未満なら速攻。それ以外は通常の遅攻へ攻守交代。ブロックでは通常交代。
- 速攻は味方が相手ゴールへ駆け上がる演出→直接コース選択。フィールドコマンドを飛ばす。GKによるセーブは可能。
- CPU攻撃は攻撃開始時にコマンド列とコースを確定。CPU守備も同時にカット／ブロックの拍とGKコースを確定。ユーザーの入力を読んで変更しない。
- CPUがシュートを選んでも、フィールド守備の4拍が終わってからGK選択。早い拍で守備が成功した場合は残りを打ち切り攻守交代。
- GKは右・左・股下。攻撃コースとの一致、GK能力、シュートの条件、乱数でキャッチ／弾く／失点を判定。予兆は65%で正しい方向を表示。キャッチは速攻、弾くは通常の攻守交代。

## 確率・素材・維持した仕様

ロング／サイド／ポスト、左右と暫定利き手、連携回数、ステイ、フェイント、連携玉、速攻、必殺技がシュート評価を変える。コースボタンの得点率は「フィールド守備通過後、CPUのGKコース3択が同確率」の平均目安。確定値ではなく、GKが選んだ方向に応じて実際の確率は変わる。

光る連携玉は約23%の通常攻撃で片側サイドに出現。その選手へパスするとトライアングル・ラッシュが発動し、次のシュートを強化。ゲージMAXでエースがシュートすると既存の学校固有必殺技を自動発動する。4種類の技名・28選手の設定は変更していない。

元PNGを48×48の全身フレームとして使用。素材、manifest、data.mjs、原本仕様は変更なし。頭部のみの切り抜き、コードでの身体の描き足し、新しい代替作画は使用していない。横視点シュート演出も継続。

## 残る課題

- iPhone/iPad実機・Safari・回転・実機のタップ感は未確認。
- 現在はフィールド3人＋GK。7対7、交代、オンライン対戦、正式反則・退場、BGM/SEは未実装。
- 同校の選手・GKは同校エースの提供素材を共用。個別選手／GK／利き手別／4方向の専用作画は未実装。
- 利き手・エース以外の能力は既存の暫定値。確率、試合時計の進み方、CPUパターンは試遊後に調整する。
- β5の連続移動・作戦・6方向コース・パッシブ予告は、この4拍方式に置き換えた。旧 `tactics.mjs` / `settled.mjs` はβ6から読み込まない。
