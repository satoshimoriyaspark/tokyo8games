## 実装

- 全4校から自校・対戦校を選択。既定は熱血 vs 疾風。
- 登録28選手を表示し、各校先頭3名＋GK（4対4）で180秒の試合。
- パスを独立した移動体として扱い、相手のパスカット・受け手への操作移行・連携ゲージを実装。
- 自動ドリブル、フェイント、スティール、ブロック、ワンツー、チーム守備。
- 通常/ジャンプ/ステップ/ループ/サイド/4必殺シュート。距離・角度・守備・能力・GK反応を反映し、必殺も必中にはしない。
- GKセーブからのアウトレットパス、失点側のセンター再開、CPUの攻撃/支援/守備。
- 斜め見下ろしコート、横視点シュート（通常0.55秒、必殺1.5秒）、演出短縮。
- 原本48pxスプライトの頭部を使い、Canvas上で肘と膝を曲げた48pxフレームを生成。走行8F、ボールは別描画。
- タッチスティックと同時タッチ、PCキーボード、長押し、操作解除、一時停止、バックグラウンド停止、結果画面/再戦。
- 新規サーバー処理・外部サービス・環境変数・音声依存なし。

## 操作

- 左スティック / 矢印 / WASD: 移動・ドリブル、上下入力でシュートコース。
- A / Z: パス、守備はパスカット。
- B / X: 離してシュート、長押しでチャージ。守備はブロック。
- C: フェイント、守備はスティール。
- L/R / Q/E: 操作選手切替。
- 技 / V: ジャンプ・ステップ・ループ・サイド。
- 連携 / Space / A+B: ワンツー・チーム守備。
- Esc: 一時停止。自校のエースがゲージMAXかつ0.55秒以上チャージで必殺。

## 既知の制約・今後の課題

- 登録7名のベンチ交代、7対7、2人/オンライン対戦は未実装。
- 4方向専用の正式作画、個々の控え選手専用スプライト、BGM/SEは未実装。
- 既存PNGは簡素な試作スプライト。企画ビジュアルの精細な16bitキャラクターとは異なる。既存素材を保ち関節描画を改善した段階。
- エース以外の能力は特徴から設定した試遊用の暫定値。4校間のバランスは調整前。
- ステップ/ジャンプは演出とチャージの差を中心にした簡易表現。ループは弾道、サイドはブロック補正あり。
- 反則（3歩/3秒、7mスロー、退場など）の正式競技ルールは省略したアクション試遊版。
- スマホ横画面を優先。縦画面は横向き案内と縮小表示。
- iPhone/iPad実機、Safariでの同時タッチ/回転/復帰は本番前に確認が必要。
