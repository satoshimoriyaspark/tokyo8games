# 熱血ハンドボール7 — tactical β4

開発ブランチ `feature/handball-playable-beta3` のPreview専用。`/handball`。本番反映はユーザー確認後。

## 今回の修正

β3では元画像の頭部だけを使い、体をCanvasで生成していた。β4はこの処理を削除し、4エースの原本PNGをmanifestに従って48×48で切り出し、全身フレームをそのまま再生する。元画像内にボールがあるため、保持・投球準備中にボールを重複描画しない。待機4、走行8、ドリブル6、パス5、シュート8、転倒4、喜び4フレームを使用。

味方は移動・パス・ドリブル・守備を自動で行う。人が決めるのはシュートの開始とコース、および相手シュートに対するGKの対応。味方の自動シュートはない。スティック／キーボードによる移動、任意のパス・フェイント・奪取も可能。

- 全4高校から自校と対戦校を選択。初期対戦は熱血 vs 疾風。CPUは「やさしい」が初期値。「ふつう」も選択可能。
- 3人＋GK、180秒、1回の攻撃26秒。コース選択中・演出中は時計停止。
- B「ねらう」→ 6コースの確率を比較 → 選択 →「このコースへシュート！」。戻ってパスや移動もできる。
- 距離・コートの左右・利き手・守備圧力で確率が変化。ロング（強打／バウンド）、サイド（ニア／ファー）、ポスト（浮かせる／足元／股下）。左右は攻撃する選手から見たゴールの向きで統一。
- 連続パス1回につき得点確率+5ポイント、最大+25。奪取されるとリセット。
- 光る連携玉が出現。取得で「トライアングル・ラッシュ」の連続パス演出と次のシュート+16ポイント。守備時は4秒の連携プレスと、奪取後の次のシュートへの加算。
- 相手シュートは先にコースを抽選し、70%の確率で正しい予兆を表示。プレイヤーの選択後にCPUがコースを変える処理はない。
- GKの移動先6方向と「キャッチ狙い／弾く優先」を選択。結果はキャッチ／弾く／失点。方向が合うとセーブしやすく、弾く優先はキャッチ率を下げてセーブ率を上げる。
- キャッチ時は「速攻！」、10秒間加速し、次のシュート+14ポイント。発射・時間切れ・ボール喪失で消費／解除。弾いた球はルーズボールとして両チームが争う。
- ゲージMAXのエースは必殺を選択。4必殺名・効果を保持し、+18ポイント。必中にせず上限94%。
- 得点後の再開タイマーが負数になって次のシュートができなくなる不具合を修正。

確率は実際の競技統計ではなくゲーム用の暫定バランス。各補正は百分率への加算（ポイント）。最終的には範囲制限と整数丸めがかかる。

## 正式資料と暫定設定

Google Drive「熱血ハンドボール」内の仕様書v1、アニメーション仕様v1、スプライトv1、β2、ロゴ、ビジュアル案を参照。仕様書は `docs/spec-v1.txt`、`docs/animation-v1.md` に保存。素材は `assets/` に原本を保持。

28選手の名前・ポジション・特徴、4エースの能力、4必殺技を保持。利き手は原本に記載がないため、RB/RWと白鷺のれんを左利き、他を右利きとする暫定値を追加し、選手一覧にも「暫定」と表示。エース以外の能力も試遊用暫定値。

## 操作

- B / X: 手動でシュートコース選択を開く。
- コースをタップ、または1〜6キーで選択し、決定ボタン／Enterでシュート・GK対応を確定。
- A / Z: 手動パス。守備中はパスカットを狙う。
- C: フェイント。守備中は近くの相手からスティール。
- 左スティック / 矢印 / WASD: 選手を手動移動。離すと自動に戻る。
- L/R / Q/E: 操作選手変更。パスを受けた選手へは自動で操作が移る。
- Esc / Ⅱ: 一時停止。タブが非表示になったときも停止。

## 検証

`node --test games/handball/tests/engine.test.mjs` — 13項目成功。

28名保持、味方の自動移動とパス／自動シュートなし、実際のパス受け渡し、連携による確率増加と上限、左右・利き手と3種類のシュート位置、選択中の時計停止、連続得点後の再選択、4必殺の発動条件、CPUコースの事前確定、GKの3結果、速攻の消費／失効、連携玉と特殊連携、4校の3分間完走を確認。

Node Canvasで原本4枚の156フレームと、切り出した全身フレームのRGBA画素がすべて一致。コート・横視点シュートの描画にも例外なし。

CPU調整の自動試合を各難易度40試合。3パス後に最高確率コースを選び、GKで予兆に従うテスト操作で「やさしい」は平均7.65対0.60、「ふつう」は6.95対1.30。人間の体感テストではない。初回試遊で勝ちやすい方向に調整しており、熟練者向けの難易度は今後の課題。

クラウドChromeでPreviewのログイン不要アクセス、元スプライトの全身表示、味方の自動移動・パス、ロング／左サイド／ポストの6コース表示、3パスで+15ポイント、コース選択取消、手動シュートから得点・再開・2回目のシュート選択を確認。ゲーム由来のconsole errorなし（ブラウザ拡張のログを除く）。追加のブラウザ検証結果はDraft PRにも記録。iPhone/iPad実機・Safari・実機同時タッチは未確認。
