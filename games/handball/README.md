## β5：遅攻の組み立て

味方は自動で運び、両サイドと中央に広がる。キャッチ後は10秒の速攻。そこでシュートしなければ、遅攻の陣形へ自然に戻る。シュートは常にプレイヤーが開始・確定する。

- **おまかせ**：左、中央、右へパスを回し、ときどきクロスを組み込む。
- **左へ／右へ**：中央と指定サイドでパス交換。反対サイドは幅を保つ。
- **クロス**：中央と右の選手が交差し、左の選手がポストへ入る。前半2秒／後半4.5秒の移動先を持ち、実際に歩いて位置を変える。瞬間移動や指示ボタンだけの確率加算はない。再使用は10秒周期。
- 守備はボールを見て、時間差で横へスライド。同じ側のパス交換が続くとその側を重点的に守る。クロス序盤にはマークの受け渡しも発生。
- シュートからゴール各コースへの経路、守備との距離、GK位置を判定し、コース別に最大+14〜-18ポイントを加減算。上コース／低いコースの守備補正も異なる。守備が戻れば有利さは失われる。
- 狙い目の選手にCHANCEリングを出し、上部に状況を表示。6コース選択画面には各コースの「守備 +○pt／-○pt」を表示する。
- パス回数による基本ボーナスは維持。守備が薄い場所へ運び、今打つか、もう一度つなぐかを選ぶ。

試遊版はフィールド3人＋GKのため、6人の攻撃陣形をそのまま再現するものではない。クロス中は出場選手が一時的にポスト役を担い、登録ポジションは変更しない。

## パッシブ予告（試遊用の簡略判定）

β4の「攻撃26秒で一律交代」を撤廃。停滞を蓄積し、16相当になると予告。ゴール方向への前進や大きな左右展開は予告までの猶予を増やす。単にボタンを押すだけでは猶予は増えない。

予告後は4本のパスを成立させてもシュート可能。5本目が成立した時点、または予告から20秒で相手ボールへ。選択・演出・一時停止中は計時しない。シュートで予告を解除する。特殊連携のパスもカウントする。

「予告後4パス」の考え方はIHFの2025年7月版Rule 7:12 / Clarification 4を参照。16相当・20秒、センター再開、前進による猶予などはこのゲームの独自簡略化で、公式ルールの完全実装ではない。
参照：https://www.ihf.info/sites/default/files/2025-07/09A%20-%20Rules%20of%20the%20Game_Indoor%20Handball_E.pdf

## 維持している機能

- 全4高校から自校と対戦校を選択。初期は熱血 vs 疾風、CPU「やさしい」。「ふつう」も選択可能。
- 28名の名前・ポジション・特徴、4エースの能力、4必殺シュートを維持。先頭3名＋GKが出場。
- 元PNGをmanifestに従って48×48の全身フレームとして再生。頭部のみの利用やコードによる体の描き足しはしない。待機4、走行8、ドリブル6、パス5、シュート8、転倒4、喜び4。画像内のボールと飛翔中のボールを重複させない。
- 斜め見下ろしコート、横視点シュート、演出短縮、180秒試合、結果・再戦。
- B「ねらう」→ 時間を止めて6コースを比較 → 選択 → シュート確定。戻ってパスや移動も可能。
- ロング（強打／バウンド）、サイド（ニア／ファー）、ポスト（浮かせる／足元／股下）。ポストはゴールに近い中央域。左右は攻撃側から見た向きに統一。
- パス1回+5ポイント（最大25）、光る連携玉からトライアングル・ラッシュで次の一撃+16、キャッチ後の速攻で次の一撃+14、ゲージMAXのエースの必殺+18。ボーナスは重ねられるが最終得点確率の上限は94%。
- GKの移動先6方向とキャッチ／弾く優先。キャッチ／弾く／失点の3結果。相手は先にコースを決め、70%の的中率で予兆を表示。GKの選択を見てコースを変えない。
- 弾いた球はルーズボール。キャッチ後は速攻。速攻／連携の加算は次のシュートで消費し、ボール喪失で解除。速攻は10秒で失効。

## 操作

- 中央の4ボタン：おまかせ／左へ／右へ／クロス。PCはU／J／K／V。
- B / X：シュートコース選択。コースはタップまたは1〜6キー、決定ボタンまたはEnterで確定。
- A / Z：手動パス。守備時はパスカット。
- C：フェイント。守備時はスティール。
- 左スティック／矢印／WASD：選手を手動移動。離すと自動へ。
- L/R（スティック横）／Q/E：操作選手変更。
- Esc／Ⅱ：一時停止。タブ非表示でも停止。
