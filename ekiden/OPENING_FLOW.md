# オープニングとスタート導線

2026-10-11実装。対象は `feature/ekiden-prototype` の `ekiden/`、Previewのみ。

## 画面の流れ
ロゴ「はじめる」→ ストーリー → ゲーム画面で20人が整列（2秒）→ 3・2・1 → スタート。
コース・たすき・難易度は、ロゴ画面の「コース・たすき・難易度をえらぶ」で変更し、「この設定で決定」でロゴへ戻る。選んだ内容をロゴ画面に表示する。

## ストーリー
- 亀有わっしょいバトルの `games/kwb/style.css` にある、中央の高さ60vhのパネル内で約23秒かけて下から上に流す表現を参照。
- 本文は駅伝用の新規文章。選んだ区間・ルートを最初に表示。
- 自動終了、画面タップ、「スキップしてスタート」のどれでも整列・カウントダウンへ進む。
- タイトルへ戻った後や重複入力による遅延スタートは発生させない。
- タブ非表示中は文字スクロールを止める。
- reduced-motion 設定時は静止したスクロール可能な本文とし、ボタンで開始する。
- キャラクター素材のロードが終わらない場合は、読込状況と再試行操作を示す準備画面へ移る。

## カウントダウン
- 最初の2秒は「位置について！」。20人が順に少し前へ歩いて配置につく。続けて各数字を1秒ずつ表示。
- スタートラインは320px画面のx=254、プレイヤーは整列後x=226。4段×5人を交互にずらし、全員をラインの左に表示。
- 整列とカウント表示は上部に寄せ、集団を暗幕で隠さない。
- reduced-motion設定時は整列歩行を省き、最初から静止配置。
- 待機中は左右・スパート操作を無効化。自分と19人のAI、距離、タイム、スタミナは進めない。
- 「スタート！」で全員同時に走り出し、計時を開始。表示は0.75秒で消える。
- 待機中の一時停止やタブ移動に対応。再開時は3から数え直す。
- 再挑戦も同じカウントダウンを通る。
- タイトルや選択へ戻れば待機状態は破棄される。別画面から勝手に始まらない。
- スタート前の入力は走行に持ち越さない。

## 検証
ローカルの制御時計とCanvasによる動作確認:
- ロゴ→ストーリー→カウントダウン→レース。
- コース・20色の選択値・難易度の引き継ぎ。
- ストーリーの終了イベント、スキップ、タイトルへのキャンセル、非表示中の停止。
- 0〜2000msの整列表示、2000/3000/4000/5000msの3・2・1・スタート判定。合図までは全20人の距離・スタミナとレース時計が不変。整列の歩行は描画専用で、レースの走行状態は進めない。
- 連打による二重開始の防止。
- カウントダウン中の非表示→停止→再開で3秒を確保。
- 5区HARDで入力付きの完走シミュレーション、結果、再挑戦。
- 素材読込失敗からの復旧。
- プレイヤーの入力・体力・風・順位・地形ルールは維持。CPUの個性は下記の更新内容を適用。
実iPhone/Safariの触感・滑らかさは未検証。公開Previewのブラウザ確認とは区別する。

本番、main、ルート設定、DNS、ランキング、亀有わっしょいバトル本体は変更しない。


## CPUの個性・集団表示（2026-10-11追加）
- CPU19人に、難易度の基準速度×0.90〜1.10の固有倍率を割り当てる。倍率の平均は1.00、プレイヤーには適用しない。
- 先行型・一定ペース型・追い上げ型・ペース変化型の4種。終盤の仕掛けどころも変える。
- EASY / NORMAL / HARDの基本倍率、タップ判定、回復倍率は維持。
- 「近いCPU最大6人」と「重なった選手を省く」処理を廃止。画面内の選手は全員描画。
- 走行画面の既存スプライトは0.75倍、4段に配置。同じ段の近接者は描画位置をずらして見分けやすくする。順位・ドラフティング・進捗ゲージは実際の距離で判定する。
- スタート後5秒で、右側のスタート構図から通常の追従位置へなめらかに移る。
- 進捗ゲージの20色と、プレイヤーの黄色い印は維持。

追加のローカル検証（Node制御時計・実Canvas、実機試験ではない）:
- 整列後の20人・4段×5人・全員がライン左側・同段での重なり防止を確認。
- 整列中とカウント中の操作無効、距離・体力の凍結、開始時の計時、一時停止・3から再開、キャンセル、再挑戦を確認。
- 同条件のNORMAL開始30秒時点のCPU最前方〜最後方の距離差: 変更前0.295km → 変更後0.570km。
- 左右を0.3秒ごとに交互入力、スパートなしで完走: 1区EASY148秒/1位、NORMAL146秒/9位、HARD142秒/11位、5区NORMAL168秒/4位、6区NORMAL124秒/1位。
- 1区NORMAL・プレイヤー無操作の場合のCPU完走時間: 約149〜182秒。19人とも有限値で完走。
- 上記は一定入力の一例で、難易度バランスの最終確定ではない。
